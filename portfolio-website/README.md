# Portfolio Website Project

A modern, responsive portfolio website built with HTML and CSS, perfect for showcasing web development skills.

## 🎯 Project Overview

This is a professional portfolio website designed for web developers to showcase their skills, projects, and contact information. The website features a clean, modern design with smooth animations and full responsiveness across all devices.

## ✨ Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with gradient colors and smooth animations
- **Smooth Scrolling**: Navigation links smoothly scroll to different sections
- **Multiple Sections**:
  - Hero section with call-to-action
  - About section to introduce yourself
  - Skills section showcasing technical abilities
  - Projects section to display your work
  - Contact section with links to social profiles

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better SEO and accessibility
- **CSS3**: Modern styling with:
  - Flexbox and Grid for layouts
  - CSS Variables for consistent theming
  - CSS Animations for smooth transitions
  - Media queries for responsive design

## 📂 Project Structure

```
portfolio-website/
├── index.html      # Main HTML file with website structure
├── style.css       # CSS file with all styling and animations
└── README.md       # Project documentation
```

## 🚀 How to Use

1. Open `index.html` in any modern web browser
2. Customize the content with your personal information:
   - Update the name and title in the hero section
   - Add your own about text
   - List your actual skills
   - Add your real projects
   - Update contact links with your email and social profiles

## 🎨 Customization

The website uses CSS variables for easy color customization. You can change the theme colors in the `:root` section of `style.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --dark-color: #1e293b;
    --light-color: #f8fafc;
}
```
